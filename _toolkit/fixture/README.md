# Фикстура: чужой корпус для пробы механизма

Что это. Восемь статей о композиторах XVIII века — тема, не имеющая отношения к агентской разработке. Корпус
собран владельцем 2026-09-22 специально для проверки: механизм обязан работать на любой теме и любой раскладке,
а не только на том материале, ради которого его писали.

Откуда. Выгрузки с reddit.com/r/classicalmusic (шесть обсуждений), dzen.ru и topmira.com; у каждой записи своя
шапка с `title` и `source`.

Права. Решение владельца 2026-09-24. Первое, дословно: «Даю письменное разрешение использовать эти статьи для
моего публичного репозитория в качестве фикстуры». Второе, после того как я назвала границу: тексты принадлежат
их авторам — обсуждения участникам reddit (Die_Horen, Local-Economy7031, johndoe11110, msc8976, Novel_Ice_7772,
Free-Tadpole-486), статья автору канала «Ценители Искусства» на dzen.ru, страница — topmira.com, — и разрешение
на чужой текст может дать только его автор. Ответ владельца, дословно: «Это моя ответственность и мои риски».
Публикуем как есть, вместе с механизмом.

Что для этого сделано. Атрибуция полная: у каждой записи в шапке адрес источника, у семи из восьми — автор записи;
у страницы topmira.com подписи нет, стоит адрес сайта. Ничего из этого корпуса не выдаётся за своё.

Порядок отзыва. Правообладателю достаточно открыть issue в репозитории механизма: запись убирается по первой
жалобе, без обсуждения и без встречных условий. Это не формальность — так порядок назван вслух до публикации, а
не после первой претензии.

Как пользуются. Проба берёт фикстуру по умолчанию (`python3 _toolkit/tasks.py probe`, путь меняется переменной
`WIKI_FIXTURE`): собирает чистый экземпляр без материала владельца, принимает эти источники приёмом
(`_toolkit/ingest.py`), прогоняет первую команду и линтер. Машинная сводка каждого прогона —
`_staging/audit/probe-<дата>-<NN>.json` (файл на прогон), там же счёт по разделам: по нему сравнивают прогоны
между собой — `python3 _toolkit/probe_instance.py --compare <A.json> <B.json>`.

Для полной пробы локальный bundle задаётся явно:

    python3 _toolkit/probe_instance.py --domain _toolkit/fixture/user-domain.local.tsv --schema _toolkit/fixture/user-schema.local.md --contract _toolkit/fixture/user-contract.local.json

Чего в фикстуре нет намеренно. Полной вики, разметки страниц и материалов владельца нет: чужой корпус приходит
сырым, а объявленные домен, локальный schema и контракт проверяют, что проверки становятся применимыми без
подстановки чужих значений.

Владелец, для которого механизм проверяется, описан карточкой `_toolkit/fixture/user.md`, его объявление домена —
`_toolkit/fixture/user-domain.local.tsv`.
