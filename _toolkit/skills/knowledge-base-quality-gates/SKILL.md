# Ворота качества базы знаний

## Перед коммитом

- Прогони `python3 _toolkit/tasks.py lint`: ноль проблем во всех разделах.
- Новый раздел линтера принимается только вместе со своей канарейкой; правка чекера — с перезапуском аттестации: `python3 _toolkit/tasks.py canary`.
- Дефект, замеченный глазом, закрывается новым механическим чеком, а не обещанием быть внимательнее.
- Числа в прозе берутся из машинных сводок того же прогона, никогда руками.

## Перед вскрытием пакета

- Пакет собирается одним прогоном генератора; письмо — задачей отправки по контракту, не руками: `python3 _toolkit/tasks.py send`.
- Замороженная копия — по хешу содержимого, не по дате; утверждения о прошлом сверяются только с ней.
- Открытое и отклонённое — только `debt.tsv`; отказ без причины и посыла не считается.

## Перед приёмкой поставки

- Приёмка и проба — на копии, не на живом дереве: `python3 _toolkit/tasks.py delivery`, `python3 _toolkit/tasks.py probe`.
- Карта называет каждый файл поставки; новый файл без строки замысла не принимается.
- Изменение механизма — планом списком, работа — только по слову владельца.

## Делегирование

- Детям — преобразования и чтения; суждения (уверенность, свидетельства, удаление, таксономия) решает и пишет в журнал только родитель.
- Отчёт ребёнка — машинопроверяемый конверт; покрытие проверяется до слияния, а не после.
