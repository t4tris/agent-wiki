# Контракт отчётов подагентов v1.0

Действует для делегированных задач, где дочерний агент возвращает результат родителю. Механизм проверяет
форму; локальный контракт экземпляра объявляет допустимые виды отчётов и их правила.

## Граница

`contract-v1.md` задаёт оболочку и способ проверки. Полный словарь видов, полей, типов, `enum`, `required`
и дополнительных правил хранится в локальном файле, путь к которому объявляет ключ `contract` в
`domain.local.tsv`. Механизм не содержит запасного словаря и не угадывает названия отчётов или значения полей.

Если локальный контракт не объявлен или файл отсутствует, любой конкретный `kind` отклоняется как неизвестный.

## Оболочка

Отчёт — один JSON-объект:

```json
{
  "contract_version": "1.0",
  "kind": "local-kind",
  "items": [],
  "failures": []
}
```

`items` — массив объектов. `failures` — массив объектов с полями `what`, `reason` и `retry_by_parent`.
Пустое значение массива — `[]`; `null` и строки вместо массивов запрещены. Идентификаторы, если они
объявлены, должны быть уникальны внутри `items`.

Дочерний агент возвращает отчёт и не пишет файлы вики или источников. Родитель сохраняет результат и
запускает валидатор:

```bash
python3 _toolkit/check_contract.py --wiki . report.json
```

Коды возврата: `0` — отчёт принят, `1` — JSON прочитан, но нарушен контракт, `2` — файл не разобран.

## Локальное объявление вида

Каждый объект в `contract-v1.local.json` имеет форму:

```json
{
  "item": {"field": "str|int|bool|list|dict"},
  "enums": {"field": ["value"]},
  "required": ["field"]
}
```

Необязательные общие расширения:

- `items_alias` — имя массива, совместимое с `items` для конкретного вида;
- `rules.nonempty` — поля, которые не могут быть пустыми;
- `rules.min_length` — минимальная длина строковых полей;
- `rules.required_if` — условно обязательные поля:
  `{"when": {"field": "field_a", "equals": "value_a"}, "fields": ["field_b"]}`;
  условие также может использовать `in` или `contains_any`;
- `rules.dict_enum` — допустимые значения значений словаря:
  `{"field": "field_a", "enum": "enum-name"}`.

Условные правила и значения enum являются данными локального контракта. Валидатор не содержит имён
конкретных видов или полей.

## Приёмка после формы

Валидатор проверяет только контракт и общие правила объявленного вида. Содержательные решения,
принадлежность источнику, адреса страниц и правила конкретного шага проверяют принимающие скрипты.
