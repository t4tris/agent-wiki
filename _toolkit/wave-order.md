# Наряд волны: шаблон

> Наряд — текст, по которому работают дети волны. Живёт в репозитории, а не в памяти сессии и не в аргументах
> вызова делегирования: иначе правило нельзя проверить, а наряд нельзя переиспользовать. Заполняется на каждую
> волну и лежит рядом с её отчётом (`_staging/audit/`). Требование к составу наряда — `_toolkit/ingest-wave.md`.

## Что заполнить

| пункт | что писать |
| --- | --- |
| волна и дата | номер/тема волны, дата, кто родитель |
| вход | отбор (`<файл отбора>.json`), источники слоя 1, диапазон сообщений |
| дерево контекста | `python3 _toolkit/tree_bundle.py --wiki . --budget 120000 --write`; свод тезисов — `stance_context.py`; сколько волн чтения получилось |
| работы | что именно делает волна: карточки, страницы, боли, карта конфликтов, реестры |
| детям | по каждому ребёнку: понятие или источник, полный список файлов, что он пишет |
| выжимки | формат `kind: extracts` (см. `extracts.py`), куда складывать (`_staging/extracts-inbox/<слаг>.json`) |
| приёмка | `python3 _toolkit/check_new_pages.py --wiki .`, `python3 _toolkit/lint_wiki.py --wiki .` |
| **один писатель** | список файлов, которые детям трогать запрещено: `wiki/index.md`, `log.md`, панели владельца, «Где использован» в копиях, карта структуры, счётчики и производные реестры, общие скрипты волны — их закрывает родитель |
| чего не делать | не заводить дубль страницы; не править чужие страницы, кроме одной ссылки в «Связях»; не выдумывать факты и цитаты; не писать в `raw/` |
| закрытие волны | чеклист родителя: страницы в индексе (§3), сироты (§2), `log.md`, «Где использован» (§42), панели (§50), числа (`tasks.py numbers`), выжимки вклеены (`extracts.py check` → ноль), линтер по разделам волны |

## Формулировки, которые должны попасть в наряд дословно

- «Анализ идёт по понятиям, а не по словам: назвать два–пять понятий источника и по каждому проверить, есть ли страница или её раздел».
- «Страница рождается из материала: сначала прочитанные источники, потом разделы; каркас разделов — следствие материала».
- «Цитата приводится дословно и берётся из источника, объявленного в шапке страницы (проверяет §58); свои формулировки в кавычки не берутся».
- «Общие файлы правит родитель: см. список „один писатель“».
- «Отчёт о выжимках — `kind: extracts`, иначе `extracts.py collect` его не примет».
